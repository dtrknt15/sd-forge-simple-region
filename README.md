# sd-forge-simple-region

**「普段のポジティブプロンプトはそのままに、指定した範囲へ直感的にプロンプトを追加する」** ことだけに特化した、Stable Diffusion WebUI Forge / Forge Neo 用のシンプルな領域指定（Regional Prompting）拡張機能です。

## コンセプト

多機能な領域指定拡張機能は便利な反面、特殊な区切り文字やモード切替、共通プロンプトのルールなどを覚える必要があり、気軽に使うには複雑になりがちです。

`sd-forge-simple-region` は機能を最小限に絞り、以下のように役割をシンプルに分けています。

- **通常のポジティブプロンプト欄**：画面全体・背景・画風・品質タグなどの共通プロンプト
- **Simple Region 側**：キャンバス上で範囲を指定し、そこに追加したいプロンプトと重みを入力

## 主な機能

- **直感的なキャンバス操作**：マウスドラッグで範囲を描画、クリックで選択・移動、四隅のハンドルでリサイズ
- **ワンクリック N 分割**：分割数を指定して「横分割（左右）」「縦分割（上下）」を自動配置
- **解像度連動**：「解像度更新」ボタンおよび WebUI の Width / Height 変更に連動してキャンバスのアスペクト比を更新
- **ガイド用背景画像**：キャンバス下部の「背景画像」ボタン（またはキャンバスへの画像ドロップ）、img2img タブでは「i2iから取得」ボタンで下絵を表示可能
- **通常プロンプトの引き継ぎ切り替え**：「通常プロンプトを領域にも引き継ぐ」チェックボックスで結合／分離を切り替え可能
- **重み調整**：全体（背景）の重みと、各領域ごとの重みスライダー（`0.10` 〜 `2.00`）

## 対応モデル

- SDXL 系（Illustrious / Pony 等）
- SD 1.5 系
- Anima 系（Forge Neo）

## インストール方法

1. WebUI の **Extensions → Install from URL** にこのリポジトリの URL を貼り付けてインストールする、または `extensions/` フォルダ配下に `git clone` してください。
2. WebUI を再起動すると、txt2img / img2img の下部に **Simple Region** アコーディオンが表示されます。

> **Note**: 他の領域指定・Attention Couple 系拡張機能（`sd-forge-couple` 等）と同時に有効化すると処理が競合するため、併用時は片方を無効にしてください。
